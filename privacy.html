Privacy Policy — CINERYN FILMS YouTube Agent

Effective date: October 14, 2026

Data accessed

With the channel owner's Google OAuth authorization, the application may access YouTube channel identity, owned video metadata, YouTube Analytics metrics, and permissions needed for explicitly approved video/account-management actions such as uploads, metadata updates, scheduling, or comment-related operations where YouTube permits them.

Purpose and use

This data is used only to provide private channel analytics, creator decision support, and owner-requested YouTube actions for CINERYN FILMS. Google user data is not used for advertising and is not sold.

Storage

OAuth tokens are stored outside the public source repository in the owner's local authorized runtime. Public repositories must not contain OAuth access tokens, refresh tokens, client secrets, passwords, cookies, or authorization headers.

Sharing

Google user data is not sold or shared with advertisers. Data is sent only to Google APIs and the owner's authorized runtime as needed to perform the requested function.

Retention and deletion

Locally stored OAuth credentials are kept only while the owner wants the integration connected. The owner can delete the local credential file to remove locally stored authorization state.

Revoking Google access

The owner can revoke the application's Google access at any time from Google Account security / third-party access controls. After revocation, the application can no longer access the account unless authorization is granted again.

Google API Services User Data Policy

The application's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
